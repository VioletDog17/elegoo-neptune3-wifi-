# Исходные имена файлов — WIFI NAMES

> Для установки опубликованного последнего комплекта используйте [README](README.md) и [актуальную инструкцию](docs/INSTALL-RU.md). Ниже сохранены заметки отдельного этапа разработки; пути dist относятся к локальным сборкам.


Комплект: `dist/NEPTUNE3_WIFI_NAMES` на этом ПК. Обновить нужно основную плату и дисплей.

## Что изменено

После новой загрузки принтер показывает исходное имя, включая UTF-8/кириллицу и расширение, в списке и при печати. Сетевые ответы M20/M994 также используют исходное имя. Соответствие хранится на SD и сохраняется после перезапуска. Поддерживается прежний предел загрузки: до 90 байт UTF-8 на имя.

Внутри файловой системы G-code пока остаётся с безопасным коротким именем `.GCO`; рядом сохраняется небольшой файл `.NAM` с исходным именем, размером G-code и контрольной суммой записи. Эти служебные файлы не отображаются в меню печати. Не удаляй `.NAM`, если нужно сохранить отображаемое имя. При копировании архива карты сохраняй оба файла.

Это изменение отображения и сопоставления имён, а не реализация записи FAT LFN. На ПК при просмотре самой карты будут видны короткие имена. При повреждении/отсутствии `.NAM` или несовпадении размера G-code экран безопасно показывает короткое имя.

Старые загрузки не содержат исходного имени на SD. Чтобы заменить `NFDAA5BB` настоящим именем, отправь исходный файл повторно после обновления. Старую копию эта загрузка не перезаписывает.

Повторная отправка с тем же именем создаёт отдельную копию; разные G-code не перезаписываются. После перезапуска сетевой выбор неоднозначного одинакового имени отклоняется; нужную копию можно выбрать на экране. Сразу после загрузки приложение выбирает только что переданную копию.

Дизайн STYLE сохранён: чёрный/белый значок Wi-Fi, жирный заголовок, обычная строка VioletDog. На экране увеличен только буфер `printpause.t0` с 36 до 128 байт. Имена переносятся в пределах штатного поля; очень длинная строка может не помещаться целиком визуально, но для выбора файла используется отдельное точное имя.

## Установка

1. Заверши печать, дождись остывания и выключи принтер.
2. В корень исправной FAT32-карты скопируй `mainboard/ZNP_ROBIN_NANO.bin`. Вставь карту в слот **принтера**, включи и дождись загрузки. Во время записи питание не отключать. Обычно файл становится `ZNP_ROBIN_NANO.CUR`.
3. Выключи принтер. В корень карты скопируй один файл `screen/NEPTUNE3_WIFI_NAMES.tft`.
4. Вставь её в слот **внутри дисплея**, включи и дождись успешного завершения/100%. Выключи, извлеки карту из дисплея, закрой крышку и включи снова.

## Проверка

1. Отправь через ElegooSlicer новый файл, например `Куб для принтера.gcode`, сначала кнопкой «Отправить».
2. Проверь исходное имя в открытом списке файлов. Карта извлекаться не должна; при необходимости нажми «Файлы / Обновить».
3. Перезапусти принтер и снова проверь имя в списке — оно должно сохраниться.
4. Выбери этот файл на экране; при запуске должно отображаться исходное имя и прежнее превью. Затем проверь «Отправить и напечатать» из приложения. Первую печать после обновления выполняй под наблюдением.

Комплект собран и проверен программно, на принтер пока не установлен. Проверены шесть наборов C++ тестов, в том числе сохранение UTF-8, повреждение/обрезание записи, неверный размер G-code и предельная длина. Marlin: сборка успешна. TJC: 0 ошибок/предупреждений, имя `Куб для принтера.gcode` отображено в симуляторе; сравнение HMI подтвердило единственное изменение txt_maxl 36→128.

Предыдущие рабочие комплекты остаются в `dist/NEPTUNE3_WIFI_MOD_BUNDLE` и `dist/NEPTUNE3_WIFI_STYLE`.
