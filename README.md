# Neptune 3 Pro Wi-Fi Mod

Неофициальная модификация Marlin и интерфейса TJC для **ELEGOO Neptune 3 Pro** с модулем **Makerbase MKS Robin WIFI V1.1**. Позволяет отправлять G-code из ElegooSlicer по локальной сети, сохранять его на microSD принтера и запускать печать, сохраняя работу штатного дисплея.

**Проект создан с помощью нейросетей — ChatGPT/Codex.** Нейросети использовались при исследовании протокола, написании кода, тестов, документации и интерфейса. Проверки на настоящем принтере выполняет автор проекта VioletDog. Это самостоятельный проект сообщества, не официальный релиз ELEGOO или Makerbase.

## Скачать и установить

**Последний вариант: v0.1.0-experimental — WIFI NAMES.** Компилировать самостоятельно не требуется.

- [Скачать готовый комплект ZIP](firmware/v0.1.0-experimental/Neptune3-WiFi-v0.1.0-experimental.zip?raw=true).
- [Пошаговая установка и настройка слайсера](docs/INSTALL-RU.md).
- [Совместимость, состав сборки и SHA256](firmware/v0.1.0-experimental/README.md).

В ZIP находятся прошивки **основной платы и экрана**. Они устанавливаются через разные слоты microSD. Не копируйте весь ZIP на карту: сначала распакуйте его и следуйте инструкции.

## Возможности

| Функция | Что делает модификация |
|---|---|
| Передача G-code | ElegooSlicer → MKS Wi-Fi → microSD основной платы |
| Запуск из слайсера | «Отправить» и «Отправить и напечатать», а также пауза и остановка |
| Статус | Температуры, состояние печати, время и прогресс по протоколу MKS |
| Список файлов | Автоматическое перечитывание после загрузки и кнопка «Файлы / Обновить» на первой странице |
| Превью | Общий обработчик встроенной Elegoo-картинки при локальном и сетевом запуске |
| Имена файлов | Приём UTF-8, в том числе кириллицы; сохранение исходного имени после перезапуска |
| Дисплей | Заголовок NEPTUNE 3 PRO WIFI MOD, небольшой белый/чёрный значок сети, строка WIFI mod by VioletDog |
| Защита загрузки | Проверка последовательности и размера, временный файл, завершение до разрешения запуска; существующие файлы не перезаписываются |

Это **протокол MKS**, не сервер OctoPrint, Klipper или ESP3D. Веб-страница самого Wi-Fi модуля пока остаётся штатной сервисной страницей настройки; отдельная панель управления в этот выпуск не входит. Произвольные команды движения и нагрева через Wi-Fi сейчас отключены.

## Под какое оборудование собраны файлы

| Компонент | Целевая конфигурация |
|---|---|
| Принтер | ELEGOO Neptune 3 Pro, штатная механика и конфигурация |
| Основная плата | ZNP Robin Nano_DW V2.2 |
| Цель компилятора | marlin_MKS_F401RC / STM32F401RC, 84 MHz, 256 KiB flash, 64 KiB RAM |
| Загрузчик | Штатный SD-загрузчик; приложение с offset 0x8000, загрузчик в BIN не включён |
| Wi-Fi модуль | Makerbase MKS Robin WIFI V1.1, штатный бинарный протокол MKS |
| Экран | TJC4827X243_011; наклейка ZNP4827X243_011C_Z15, интерфейс 272×480 |
| Слайсер, использованный при проверке | ElegooSlicer 1.5.3.5, тип хоста MKS |

**Не используйте эти бинарники для Neptune 3 Plus/Max, другой платы или другого экрана.** На тестовом принтере пользователь сообщил маркировку MCU STM32F402RCT6, тогда как схема и исходная сборка указывают F401RC. Параметры заводской цели компиляции не менялись; это не отдельная подтверждённая сборка для произвольных F402.

## Статус проверки

Передача файлов, запуск из ElegooSlicer, работа температур, автообновление списка, кириллица при загрузке и превью подтверждены автором на предыдущих сборках на одном принтере.

**Последняя сборка WIFI NAMES с постоянным соответствием исходных имён пока не прошла аппаратную проверку.** Для неё выполнены сборка Marlin, шесть наборов C++ тестов и компиляция/симуляция TJC без ошибок и предупреждений. Оба состояния монохромного значка и русское имя на странице печати проверены в симуляторе. Разделение этих результатов намеренное: успешные тесты не заменяют проверку конкретного устройства.

Перед установкой сохраните содержимое карты, версии и калибровки/Z-offset. Готовые BIN/TFT не являются резервным дампом вашего принтера. После обновления проверьте температуры и первый слой под наблюдением.

## Как сохраняются имена

На FAT-карте G-code хранится под безопасным коротким именем, например `NFDAA5BB.GCO`. Рядом создаётся `.NAM` с исходным UTF-8 именем, размером G-code и контрольной суммой записи. Экран, список M20 и статус M994 используют исходное имя. **Сохраняйте `.NAM` вместе с G-code.** На ПК при просмотре карты короткие имена всё ещё видны: это не реализация записи FAT LFN.

- Имя ограничено 90 **байтами UTF-8**, не 90 русскими буквами.
- Старые загрузки нужно отправить повторно: исходные имена для них раньше не сохранялись.
- Повторная загрузка создаёт отдельную копию. После перезапуска неоднозначный сетевой выбор одинаковых имён отклоняется; сразу после загрузки выбирается только что переданный файл.
- Длинное имя может визуально не помещаться в штатное поле, но выбор G-code выполняется по отдельному точному имени.
- Превью показывается, только если соответствующая картинка есть в G-code; произвольные форматы миниатюр других слайсеров не конвертируются.
- Штатный экран показывает до 25 файлов. Кнопка ручного обновления есть на первой странице.
