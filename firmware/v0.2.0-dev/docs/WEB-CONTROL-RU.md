# Автономная панель · v0.2.0-dev

Панель хранится **в Wi-Fi модуле принтера**, открывается по его IP из любого компьютера в той же локальной сети и во вкладке «Принтер» ElegooSlicer. Дополнительная программа на ПК не нужна. При смене роутера настройте новую сеть через значок Wi-Fi; адрес принтера после подключения может измениться.

**Статус: экспериментальная версия с частичной аппаратной проверкой.** Сборки, тесты на ПК и симулятор TJC пройдены. 13 ноября 2026 на принтере подтверждены OTA нашего ESP8266, телеметрия, выключение нагрева и загрузки 43/217141 байт без печати; русский файл отобразился с правильным именем и размером. Первая версия давала `Invalid UART frame`; в `0.2.0-dev-uart2` добавлены паузы между байтами UART. Движение, печать/пауза и смена сети ещё требуют проверки. Выпуск v0.1 сохранён отдельно.

## Что добавлено

**Проверка 14 ноября 2026:** автор подтвердил успешную отправку своего файла из слайсера после удалённого обновления Wi-Fi до uart2. Это дополняет проверки OTA, телеметрии и многоблочной загрузки; не означает, что все сценарии движения/паузы/смены сети проверены.

- Статус, процент, время печати и оценка оставшегося времени. Оценка вычисляется по проценту прочитанного G-code и может отличаться от реального времени.
- Температуры/цели сопла и стола, графики текущего сеанса; прогрев сопла для ручного извлечения филамента.
- Поиск нуля, шаги 0.1/1/10 мм, перемещения X/Y/Z и парковка. Перемещения запрещены до поиска нуля и во время печати/паузы; основная плата проверяет границы.
- Обдув модели и коэффициент скорости печати. Автоматический вентилятор хотэнда остаётся под управлением Marlin.
- Просмотр корневых G-code на SD, поиск, загрузка и запуск; пауза, продолжение и остановка с подтверждением. Остановка не является аппаратным аварийным выключателем.
- Настройки Wi-Fi в том же стиле, поиск сетей, резервная точка доступа.
- Маленький значок обновления списка на TJC вместо «Файлы / Обновить».
- Исправлена повторная запись названия текущей печати: берётся реально открытый файл, а не последняя строка локального выбора. Для поля явно используется штатный шрифт с кириллицей.

Камера и история печати не добавлены. Обновление списка файлов недоступно во время печати; последний полученный список остаётся в панели. Лимит панели — 128 файлов в корне, загрузка до 32 MiB, имя до 90 байт UTF-8. На SD остаются технические 8.3-имена и NAM-метаданные, пользователю показывается оригинальное имя загруженного файла. Вложенные папки и удаление через панель пока не реализованы.

## Установка трёх компонентов

Комплект: `firmware/v0.2.0-dev/`. Цели: **Neptune 3 Pro / ZNP Robin Nano_DW V2.2 / MKS Robin WIFI V1.1 ESP8266 4 MB / TJC4827X243_011**. Не использовать для Plus/Max или других экранов.

Актуальный ZIP: **Neptune3-WiFi-Control-v0.2.0-dev-uart2.zip**. Ранний архив без суффикса uart2 содержал ошибку UART; его Wi-Fi BIN не использовать. Если основная плата и экран v0.2 уже установлены, достаточно обновить только Wi-Fi модуль до uart2. Установленный ESP сообщает ревизию в `/api/info`.

1. Завершите печать. Сохраните настройки/Z-offset и подходящие исходные прошивки. Полного дампа установленного принтера у нас нет.
2. Обновите основную плату файлом `mainboard/ZNP_ROBIN_NANO.bin` через её microSD, как в [обычной инструкции](INSTALL-RU.md#3-обновить-основную-плату). Дождитесь загрузки, при выключенном питании уберите обновление с карты.
3. Обновите дисплей файлом `screen/NEPTUNE3_WIFI_CONTROL.tft` через слот **внутри дисплея**, как в [инструкции экрана](INSTALL-RU.md#4-обновить-дисплей). После завершения выключите питание, извлеките карту.
4. Включите принтер и откройте старую сервисную страницу Wi-Fi, например `http://192.168.3.34/`. В строке **wifi firmware** выберите только **`wifi/MksWifi.bin`** из нового комплекта и нажмите соседнюю **update**. Поле **web view** не использовать. BIN основной платы сюда загружать нельзя.
5. Дождитесь завершения и перезагрузки модуля, не прерывая питание. Затем заново откройте IP с обновлением без кэша. Новая панель встроена в MksWifi.bin, отдельный файл страницы не нужен.
6. Если старый IP перестал отвечать, найдите новый адрес в роутере. Либо подключитесь к резервной сети **NEPTUNE3-…**, пароль ****, и откройте `http://192.168.4.1/`. Значок Wi-Fi в панели позволяет выбрать домашнюю сеть 2.4 GHz и сохранить пароль. Пустой пароль сохраняет старый только для того же SSID. Открытые сети без пароля пока не поддерживаются.
7. Вернитесь в домашнюю сеть. Откройте новый IP или `http://neptune3.local/`, если mDNS работает на вашем компьютере. Зафиксируйте IP в роутере при необходимости.

Первый переход со штатной прошивки MKS на новую не проверен аппаратно. Если веб-обновление будет отвергнуто, сохраните текст ошибки. Не пробуйте случайные смещения записи. Для восстановления недоступного ESP8266 может потребоваться USB–UART 3.3 V и режим загрузчика; это отдельная операция для подтверждённой маркировки flash.

Для последующих обновлений нашей ESP-прошивки есть `wifi-tests/update-wifi.py`: без `--install` только проверяет состояние, с `--install` отправляет выбранный ESP BIN и перезагружает модуль. Штатная зелёная форма после перехода заменяется новой панелью.

## Слайсер

Тип хоста **MKS**, IP без `http://` и без `:8080`, API-ключ/URL хоста пустые. Во вкладке устройства должна открываться новая панель. Если слайсер сохранил старую страницу, переоткройте вкладку/перезапустите его. Сначала проверьте панель в обычном браузере. ПК и принтер должны быть в одной доступной друг другу сети; изоляция клиентов/гостевая сеть могут блокировать доступ. Общедоступного облачного доступа нет.

## Чеклист первого испытания

1. Панель загружается без Интернета и показывает настоящие температуры. После отключения основной платы связь должна стать недоступной, а кнопки заблокироваться.
2. Значок сети на TJC белый при подключении. В списке файлов новый значок обновления вызывает обновление без перестановки SD.
3. На пустом столе выполните поиск нуля, затем шаги X/Y/Z по 1 мм и парковку; проверьте направления. Во время печати и паузы движения из панели заблокированы.
4. Проверьте обдув модели 0/50/100%, прогрев/выключение сопла и стола под наблюдением. Профили смены филамента включают только сопло.
5. Загрузите маленький проверенный G-code с названием `Куб для принтера.gcode`. Проверьте исходное имя в панели, списке экрана и **во время печати**. Повторите запуск с TJC, из панели и «Отправить и напечатать» из слайсера. Проверьте превью, паузу/продолжение/остановку.
6. После успешной маленькой загрузки проверьте свой обычный большой файл. При ошибке не запускайте частично переданный файл; сообщение успеха выдаётся только после подтверждения SD.
7. Проверьте смену Wi-Fi и доступ из другого ПК; при неверном пароле резервный AP должен оставаться доступен.
