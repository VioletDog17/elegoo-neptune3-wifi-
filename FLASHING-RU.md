# Сборка, обновление и восстановление Neptune 3 Pro

> Для установки опубликованного последнего комплекта используйте [README](README.md) и [актуальную инструкцию](docs/INSTALL-RU.md). Ниже сохранены заметки отдельного этапа разработки; пути dist относятся к локальным сборкам.


Актуальный комплект **основная плата + экран WIFI MOD**: [WIFI-MOD-UPDATE-RU.md](WIFI-MOD-UPDATE-RU.md). Ниже также описаны прежние отдельные сборки.

## Где проект

Корень: `<папка проекта>`.
Открой в VS Code файл `Neptune3-WiFi.code-workspace` из этой папки.
Ctrl+Shift+B собирает новое окружение загрузки/печати NEPTUNE3_MKS_WIFI. В Terminal -> Run Task
также доступны базовая сборка и тесты протокола.

Исходники Marlin находятся в
`neptune3pro-main/Firmware/Mainboard/Marlin-2.1.1_TJC_029/Marlin-2.1.1_TJC_029`.
Наш модуль — `Marlin/src/feature/neptune_mks_wifi/`; подключение в
`Marlin/src/MarlinCore.cpp`, разделение портов в
`Marlin/src/lcd/extui/dgus/DGUSDisplay.cpp`, окружения — `ini/stm32f4.ini`.

## Инструменты на этом ПК

- Python 3.13 и Git уже установлены.
- PlatformIO Core 6.1.18: `.tools/pio`; пакеты STM32 и ARM GCC 9.2.1 — `.platformio-wifi`.
- Zig 0.13.0: `.tools/python/ziglang`, используется тестами автоматически.
- VS Code с C/C++, PlatformIO IDE и Auto Build Marlin уже установлен.
- STM32CubeProgrammer 2.14.0 уже установлен:
  `C:\Program Files\STMicroelectronics\STM32Cube\STM32CubeProgrammer\bin`.

Сборку запускаем нашими задачами/скриптом: они используют рабочий локальный
PlatformIO, а не повреждённое старое окружение из профиля пользователя.
Для этого сценария переустановка глобального PlatformIO не нужна.

```powershell
./wifi-tests/build.ps1 -Environment NEPTUNE3_MKS_WIFI_DIAG
./wifi-tests/build.ps1 -Environment MKS_E3_V2
./wifi-tests/run-tests.cmd
```

## Что получается после сборки

`dist/NEPTUNE3_MKS_WIFI_DIAG/ZNP_ROBIN_NANO.bin` — наше диагностическое обновление.
`dist/NEPTUNE3_MKS_WIFI/ZNP_ROBIN_NANO.bin` — новый экспериментальный вариант загрузки и запуска из слайсера. Порядок его проверки: [UPLOAD-PRINT-RU.md](wifi-tests/UPLOAD-PRINT-RU.md).
`dist/MKS_E3_V2/ZNP_ROBIN_NANO.bin` — базовая сборка из снимка исходников.
В каждой папке есть `manifest.json` с SHA256 и параметрами сборки.
**Базовая сборка не является дампом или точной копией установленной 1.1.5.1.**

Диагностическое окружение поддерживает только связь/статус.
Передача G-code и запуск реализованы отдельно в NEPTUNE3_MKS_WIFI; они ещё требуют аппаратной проверки.
Сборка проверена компилятором и тестами; аппаратная проверка впереди.
Схема/исходники указывают F401RC, сообщённая маркировка MCU — F402RCT6.
Пропуск дампа не устраняет это расхождение и не доказывает совместимость.

Экран — отдельный контроллер. Комплект WIFI MOD теперь содержит и `.bin` основной платы, и `.tft` дисплея; ставить их нужно в разные слоты по инструкции WIFI-MOD-UPDATE-RU.md. Файл `.HMI` — редактируемый проект, на карту обновления его копировать не нужно.

## Перед обновлением

По решению пользователя дамп сейчас пропускаем. Сфотографируй версии,
Z-offset и настройки калибровки; сохрани содержимое microSD на ПК.
При доступе к USB-консоли можно отдельно сохранить ответ `M503` как текст;
это список настроек, а не полный дамп EEPROM. Не отправляй M502/M500 для
резервного копирования. EEPROM AT24C32 на основной плате хранится отдельно
от flash STM32; обновление может потребовать повторной калибровки.

## Обновление основной платы через microSD

1. Заверши печать, дождись остывания и выключи принтер.
2. Скопируй нужные данные с карты. Подготовь microSD FAT32; форматирование
   удаляет содержимое карты. Используй исправную карту.
3. Скопируй **один выбранный** `ZNP_ROBIN_NANO.bin` в корень карты.
   Проверь, что расширение действительно `.bin`, без второго скрытого расширения.
4. Вставь карту в слот **самого принтера**, включи питание и дождись завершения
   обновления. Обычно около 15 секунд; не отключай питание во время записи.
5. Проверь запуск интерфейса. Признак принятия обновления загрузчиком — файл
   `ZNP_ROBIN_NANO.CUR` на карте. Это переименованный файл обновления,
   **не прочитанный из контроллера дамп**.
6. Удали файл обновления с рабочей карты или убери её после выключения.
   Сначала проверь температуры, экран, вентиляторы и концевики.
   Затем проверь калибровку и Z-offset; после перепрошивки нужна проверка уровня стола.
   Первую печать выполняй под наблюдением.

Первая аппаратная проверка нашей диагностики — работа экрана и чтение статуса
без запуска печати по Wi-Fi. Папки dist с разными окружениями не смешивать.

## Откат без дампа

В `recovery/official-1.1.5.1a-UI1.4.1/` сохранена штатная пара:
`ZNP_ROBIN_NANO.bin` версии **1.1.5.1a** и `V1_4_1_20230210.tft` версии **1.4.1**.
Это опубликованная совместимая пара, а не точная копия установленной 1.1.5.1.
Файл 1.1.5.1 без суффикса найден в историческом ZIP, но архив защищён паролем:
он скачан в `.tools/official-historical.zip`, прошивка из него не извлечена.
Источники и контрольные суммы сохранены рядом. Если экран остаётся штатным
1.4.1, для отката основной платы нужен только `.bin` по процедуре выше.

Если потребуется обновить/восстановить экран: при выключенном принтере открой
заднюю крышку дисплея, вставь FAT32-карту с одним подходящим `.tft` в **слот
внутри дисплея**, включи питание, дождись сообщения о завершении (обычно около
минуты), выключи, извлеки карту, закрой корпус и включи снова. Файл `.tft`
не переименовывается автоматически, поэтому карту нужно извлечь.
Этот шаг нужен для комплекта WIFI MOD и не создаёт резервную копию экрана.

## Когда ST-Link будет доступен

Неразрушающий дамп возможен при разрешённом чтении flash. Перед подключением
нужно проверить разводку SWD, питание и реальный размер flash. Читать нужно
с `0x08000000` вместе с загрузчиком; обычная SD-сборка начинается с offset
`0x8000` и загрузчика не содержит. Полный дамп нельзя просто переименовать
в SD-обновление. EEPROM и память дисплея сохраняются отдельно.

STM32CubeProgrammer позволяет читать память в файл. Если включена RDP,
не нажимать Read Unprotect/Unlock и не менять option bytes: снятие защиты
может стереть flash. Для копии нужны два одинаковых чтения с проверкой SHA256.
Сейчас ST-Link на ПК не обнаружен, **дамп не создан**. Если загрузчик повреждён,
обычный откат по microSD может быть недоступен и потребуется SWD.
