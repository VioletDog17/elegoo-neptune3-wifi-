# Установка Neptune 3 Pro Wi-Fi Mod

**Для актуального комплекта v0.2.0-dev-uart2 используйте [новую инструкцию трёх компонентов](WEB-CONTROL-RU.md).** Там описаны автономная панель, обновление Wi-Fi, резервная сеть и исправление обрыва загрузки. Ниже сохранена инструкция предыдущего выпуска v0.1 без веб-панели.

Актуальный комплект: **v0.1.0-experimental / WIFI NAMES**. Это экспериментальная сборка для ZNP Robin Nano_DW V2.2 + MKS Robin WIFI V1.1 + TJC4827X243_011 на Neptune 3 Pro. [Полная таблица совместимости](../README.md#под-какое-оборудование-собраны-файлы).

## 1. Скачать комплект

[Готовый ZIP](../firmware/v0.1.0-experimental/Neptune3-WiFi-v0.1.0-experimental.zip?raw=true) содержит:

```text
mainboard/ZNP_ROBIN_NANO.bin       основная плата
screen/NEPTUNE3_WIFI_NAMES.tft     дисплей
INSTALL-RU.md                     эта инструкция
manifest.json                    цель сборки, версии инструментов, хеши
SHA256SUMS.txt                    контрольные суммы
```

Также можно скачать весь репозиторий через Code → Download ZIP. Готовые файлы находятся в `firmware/v0.1.0-experimental/`. Сборка и установка программатора не требуются.

Сверьте SHA256 файлов с SHA256SUMS.txt. В PowerShell: `Get-FileHash .\ZNP_ROBIN_NANO.bin -Algorithm SHA256`; в Linux: `sha256sum ZNP_ROBIN_NANO.bin`.

## 2. Подготовить принтер

Завершите печать, дождитесь остывания и выключите принтер. Сохраните содержимое microSD, текущий Z-offset и настройки калибровки. При наличии USB-консоли ответ M503 можно сохранить как список настроек; это не полный дамп. Не выполняйте M502 для резервного копирования.

Используйте исправную FAT32-карту. Если требуется форматирование, сначала скопируйте её файлы. Полный дамп контроллеров этот проект не создаёт. Для восстановления сохраните штатные файлы именно для своей ревизии.

Модуль Wi-Fi должен быть уже установлен в соответствующий разъём платы при выключенном питании. [Карта сигналов](../wifi-tests/HARDWARE.md) описывает схему, а не произвольную распиновку переходника: модулю нужно питание 3.3 V, не подавайте 5 V на его контакты питания/логики.

## 3. Обновить основную плату

1. Скопируйте `mainboard/ZNP_ROBIN_NANO.bin` в **корень** карты, сохранив точное имя файла. Не копируйте вместо него ZIP или HMI.
2. Вставьте карту в слот **самого принтера**, не дисплея.
3. Включите питание и дождитесь нормальной загрузки. Во время записи не выключайте принтер.
4. Выключите принтер и проверьте карту: обычно загрузчик переименовывает файл в `ZNP_ROBIN_NANO.CUR`.
5. CUR — переименованный файл обновления, не считанный резервный дамп. Уберите файл обновления с рабочей карты после выключения.

## 4. Обновить дисплей

1. При выключенном принтере подготовьте FAT32-карту с **одним** файлом `NEPTUNE3_WIFI_NAMES.tft` из папки screen в корне.
2. Откройте заднюю крышку дисплея и вставьте карту в слот **внутри дисплея**.
3. Включите принтер и дождитесь явного сообщения об успешном завершении/100%. Во время записи не отключайте питание.
4. Выключите принтер, извлеките карту из дисплея и закройте крышку. Затем включите снова.
5. Не оставляйте карту с TFT внутри дисплея: файл автоматически не переименовывается и может запустить повторное обновление.

Если обновляете прошлую версию этого мода до WIFI NAMES, нужны **оба** файла. Если экран сообщает несовпадение модели, не принуждайте обновление — сначала сверьте маркировку.

Новый интерфейс узнаётся по NEPTUNE 3 PRO WIFI MOD, чёрному/белому значку сети и строке VioletDog в Settings → About Machine. Поле версии UI может показывать 1.4: проект собран из HMI репозитория, а не из дампа установленной UI 1.4.1.

## 5. Подключить Wi-Fi

Прошивка ESP8266 самого модуля в комплект не входит; используется штатный MKS Robin WIFI с бинарным протоколом MKS, не ESP3D.

Если модуль уже подключён к домашней сети, менять его настройки не нужно. Иначе подключитесь к его точке доступа и откройте штатную страницу настройки согласно руководству вашей версии MKS. Укажите домашнюю сеть и пароль, выберите режим STA, сохраните настройки и дождитесь перезапуска. Затем верните ПК в ту же локальную сеть. [Документация и исходники MKS](https://github.com/makerbase-mks/MKS-WIFI).

Узнайте назначенный модулю адрес в списке клиентов роутера. При открытии этого IP в браузере должна появляться сервисная страница MKS. Удобно закрепить адрес в DHCP роутера. Ниже `192.168.1.50` — **пример**, замените его адресом своего принтера. Доступ через Интернет для этого не требуется; не публикуйте сервис принтера наружу.

Белый значок на главной странице означает подтверждённое подключение, чёрный — отсутствие подтверждения. Потеря статуса определяется также по таймауту около 30 секунд.

## 6. Настроить ElegooSlicer

Проверенная версия — 1.5.3.5. Откройте настройки физического принтера/хоста печати:

| Поле | Значение |
|---|---|
| Тип хоста | **MKS** |
| Имя хоста / IP | IP вашего модуля, например `192.168.1.50` |
| URL-адрес хоста | Пусто |
| API-ключ / пароль хоста | Пусто |

В поле IP не добавляйте `http://`, путь или `:8080`. Нажмите «Тест», затем сохраните настройки. После нарезки используйте «Отправить» либо «Отправить и напечатать».

Вкладка «Принтер» пока показывает штатную сервисную страницу Wi-Fi модуля, а не новую панель управления. Не загружайте BIN основной платы в поле обновления Wi-Fi firmware этой страницы.

## 7. Проверить после установки

1. Убедитесь, что температуры правдоподобны, настройки/Z-offset сохранены и экран отвечает. Проверьте уровень стола и первый слой после перепрошивки.
2. Оставьте список файлов на дисплее открытым и отправьте небольшой файл через «Отправить». Он должен появиться без перестановки карты; при необходимости нажмите «Файлы / Обновить» на первой странице.
3. Отправьте файл с именем `Куб для принтера.gcode`. Проверьте имя в списке, перезапустите принтер и проверьте его снова. Уже загруженные старыми версиями файлы нужно отправить повторно.
4. Выберите файл на экране, затем отдельно проверьте «Отправить и напечатать». Для файла со встроенным Elegoo-превью должна отображаться картинка. Первую печать наблюдайте.
5. Проверьте паузу/остановку и значок сети. Присылая отчёт, укажите маркировки плат/экрана, версии, способ загрузки и наблюдаемое поведение; не публикуйте пароль Wi-Fi.

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| BIN не принят | Корень FAT32-карты, точное имя ZNP_ROBIN_NANO.bin, слот принтера и ревизию платы |
| TFT не принят | Внутренний слот дисплея, один TFT в корне, соответствие TJC4827X243_011 |
| Слайсер зависает/не соединяется | Тип MKS, правильный IP, одна локальная сеть; URL/API key пустые |
| Имя всё ещё NF… | Отправьте файл заново после обновления обеих плат; сохраняйте рядом его NAM |
| Нет превью | Проверьте наличие встроенного Elegoo-превью в исходном G-code |
| Файл не виден | Дождитесь завершения загрузки, проверьте первые 25 файлов, нажмите обновление; во время открытого файла обновление откладывается |

## Откат

Сохраните подходящую заводскую пару BIN/TFT до эксперимента. Опубликованные файлы ELEGOO и ссылки на них перечислены в [recovery/sources.json](../recovery/official-1.1.5.1a-UI1.4.1/sources.json) и [официальном репозитории прошивок](https://github.com/NARUTOfzr/Neptune_3_Pro_Plus_Max). Это не резервная копия вашей EEPROM/калибровок и не точный дамп установленной версии. Откат через SD использует те же разные слоты; при повреждении загрузчика может потребоваться ST-Link.
